## 2023-11-20 - SVG Deduplication Strategy
**Learning:** For SVGs representing static content with massive duplicate text/ASCII art sections, string manipulation combined with `<defs>` usage significantly reduces DOM complexity and file size (e.g., nearly ~50% reduction in `name-banner.svg`). `lengthAdjust` isn't inherited so keeping it in text elements and using `<use>` is ideal. Applying regex or str operations directly must happen only on the body after splitting at `</defs>` to avoid infinite `<use>` recursive loops.
**Action:** Always check SVG files for duplicate large blocks. Extract into `<defs><g id="...">` and deduplicate the references using `<use>`. Use direct Python string manipulation for exact block extraction to preserve formatting and `xml:space="preserve"` untouched.
