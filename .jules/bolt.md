## 2024-05-24 - SVG Optimization: Reducing file size by removing redundant attributes
**Learning:** SVG files, especially those with ASCII art, can become bloated with repeated attributes on every `<text>` element. Attributes like `fill="#ffffff"` and `xml:space="preserve"` can be safely moved to the parent `<g>` (group) element in most cases, significantly reducing the file size and parsing overhead without affecting the final rendering. In our case, `lengthAdjust="spacingAndGlyphs"` cannot be easily moved to the parent `<g>` tag because it is not an inheritable attribute.
**Action:** When working with SVGs containing many repetitive text elements, analyze which attributes can be hoisted to parent group elements. Use python to apply these transformations safely. Always verify the SVG renders correctly afterward.
