## 2024-05-18 - SVG Size Optimization via Defs Deduplication
**Learning:** SVG files in this codebase often duplicate massive ASCII art blocks multiple times (e.g., to create a glowing effect with different colors and filters). The `xml:space="preserve"` and length adjustments are important to maintain, but these static text nodes blow up file size.
**Action:** Extract the heavily duplicated `<text>` blocks into a `<g id="some-id">` inside the `<defs>` section. Then, replace all the duplicate blocks in the main body with `<use href="#some-id"/>`. The `<use>` tag correctly inherits the parent `<g>` styles (like `fill` or `opacity`). Make sure to only run the string replacement on the body of the SVG (after `</defs>`), otherwise it will replace the block inside `<defs>` too, creating an infinite recursion.
