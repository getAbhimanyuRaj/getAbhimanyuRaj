## 2024-11-06 - Deduplicating ASCII Art in SVGs via <defs> and <use>
**Learning:** This codebase heavily uses SVGs with multiple repeated massive ASCII text blocks to achieve CSS-like text-shadow/glow effects. Simply extracting this repeated text into `<defs>` under a `<g>` tag and replacing occurrences with `<use href="#id"/>` dramatically reduces file size and DOM complexity. Standard XML parsers in Python (`xml.etree.ElementTree`) can strip out critical layout attributes (like `xml:space="preserve"`) during re-serialization.
**Action:** When extracting large repeated text to `<defs>` in SVGs in this project, use targeted Regex or string replacement (being careful to split the document body from the `<defs>` to prevent infinitely recursive `<use>` replacements) rather than full XML parsing to preserve all layout attributes.
