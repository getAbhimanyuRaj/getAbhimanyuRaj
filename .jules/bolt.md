## 2024-10-19 - Extracted repeated SVG ASCII text blocks into `<defs>`
**Learning:** In SVGs with repeated identical complex blocks (like the ASCII text banners), grouping the text into a `<g id="...">` within `<defs>` and referencing it multiple times via `<use href="#..."/>` can significantly decrease file size. However, any text specific attributes like `xml:space="preserve"` and `lengthAdjust="spacingAndGlyphs"` must be kept strictly on the original `<text>` elements being extracted. Also, standard Python string replacements for these specific tags must be done very carefully using targeted Regex as opposed to generic substring replacements. Finally, simple static README assets do not warrant calling the `frontend_verification_instructions` tool, just local structural validation.
**Action:** When extracting large blocks into `<defs>`, ensure no styling attributes are accidentally lost or overwritten, and always use local Python `xml.etree.ElementTree` scripting to guarantee valid XML output.
